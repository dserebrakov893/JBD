# JBD (just business, darling)

Сайт-визитка холдинга JBD и сервер заявок. Владелец: Шеф (ИП). Общение с владельцем на русском.

## Что где
- `site/index.html` — весь сайт одним файлом: 3D-интро с визитницей (three.js r160 из jsdelivr, модель GLB встроена base64), страницы Продукты / Решения / О нас / Подписано, корзина «Ваш проект», подвал с формой. RU/EN через словарь `data-t`.
- `site/privacy.html`, `consent.html`, `offer.html` — юридические документы (RU/EN).
- `server/server.mjs` — Node 18+, без зависимостей. Отдаёт сайт из `site/` (в памяти, с gzip) и принимает POST `/lead`: сначала пишет заявку в `$DATA_DIR/leads.jsonl` (Volume на Railway), потом шлёт в Telegram-бот. Токены только в переменных Railway, никогда в репозитории.
- Хостинг: Railway, один сервис, `npm start`. Пуш в `main` выкладывает автоматически. Подробности в README.md.

## Правила по тексту и дизайну
- Домен и почта: justbusinessdarling.com, hello@justbusinessdarling.com.
- Букву «ё» не трогать: дизайнер ставит её осознанно.
- NIKA всегда латиницей и заглавными. Сайт NIKA: www.mynika.online, VetFinance: www.vetfinance.online.
- Без подчёркиваний ссылок; при наведении текст жирнее.
- Реестр «Подписано»: работы попадают туда только с согласия клиента.
- Анимации: пружины и плавные кривые (cubic-bezier(.32,.72,0,1)), без пауз посреди движения.

## Интро (3D)
- Модуль `<script type="module">` в index.html. Главные константы времени: TD, TL, TB0/TB1, THAND, T_LID, SWEEP0/1. Поза покоя `B`.
- Летящие карточки — снимки настоящих `#front` и `#back`, посадка точно в их прямоугольники, затем 3D выгружается.
- Отладка: `window.__jbdClock` (мс) управляет временем, `window.__jbdNoAuto = true` отключает автооткрытие.

## Проверка перед пушем
- Открыть index.html локально: интро, все страницы, RU/EN, мобильная ширина 390px.
- Форма: при `window.JBD_LEAD = "/lead"` заявки идут на сервер; пустая строка открывает письмо на почту.
