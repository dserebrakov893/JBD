# JBD: сайт и бот заявок

Один сервис на Railway: `server/server.mjs` отдаёт сайт из `site/` и принимает заявки с форм (`POST /lead`). Каждая заявка сначала пишется в `leads.jsonl` на диске сервиса, потом уходит в Telegram-бот. Railway сам собирает и выкладывает проект при каждом пуше в `main`.

Node 18+, сторонних пакетов нет.

## Запуск на Railway
1. New Project → Deploy from GitHub repo → этот репозиторий. Railway найдёт `package.json` и запустит `npm start`.
2. **Volume.** В сервисе: Settings → Volumes → Add Volume, путь монтирования `/data`. Без него заявки стираются при каждом деплое.
3. **Variables:**

   | Переменная | Значение |
   |---|---|
   | `BOT_TOKEN` | токен бота от @BotFather |
   | `CHAT_ID` | куда слать заявки (у группы с минусом) |
   | `DATA_DIR` | `/data` |
   | `TG_MODE` | `full` (вся заявка в Telegram) или `short` (только номер и состав, контакты остаются на сервере) |
   | `ALLOW_ORIGIN` | не обязательно: другие сайты, которым можно слать заявки, через запятую |

   `PORT` Railway задаёт сам.
4. **Домен.** Settings → Networking → Custom Domain → `justbusinessdarling.com`. Railway покажет CNAME-запись: добавьте её у регистратора. Для голого домена без www нужен регистратор с CNAME flattening / ALIAS (например, Cloudflare DNS). Иначе используйте `www` и редирект с голого домена.

Проверка: `https://<домен>/health` отвечает `{"ok":true}`. Отправьте заявку с сайта: она придёт в Telegram, а в логах сервиса будет её номер.

## Бот
1. @BotFather: `/newbot`, получите токен.
2. Напишите боту что-нибудь (или добавьте его в рабочую группу).
3. Откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates`, найдите `"chat":{"id": ...}`.

## Защита
Скрытое поле от ботов, не больше 5 заявок с одного IP за 10 минут, ограничение размера. Заявки принимаются только со своего домена (и из `ALLOW_ORIGIN`). Если Telegram недоступен, заявка всё равно сохранена, номер есть в логе.

## Локально
```bash
npm start            # http://localhost:8787
```
